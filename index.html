Microphone is blocked

Your browser is blocking the microphone for this page, so it can’t ask again. Allow it once and it will work:
  1. Tap the lock / ⓘ icon left of the address bar
  2. Open Permissions / Site settings
  3. Set Microphone → Allow
  4. Come back here and press Try again
